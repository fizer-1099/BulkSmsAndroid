# پیامک‌یار — نسخه ۲.۳

اپلیکیشن مدیریت و ارسال پیامک با سیم‌کارت داخل گوشی، با رابط کاربری کاملاً فارسی و راست‌به‌چپ.

## امکانات
- داشبورد حرفه‌ای کارت‌محور
- رابط کاربری کاملاً فارسی و RTL
- مدیریت مخاطبین و جستجو
- گروه‌بندی
- فهرست عدم دریافت
- انتخاب سیم‌کارت
- قالب‌های آماده
- شخصی‌سازی با `{نام}`
- پیش‌نمایش پیام
- تأیید قبل از ارسال
- نوار پیشرفت و وضعیت لحظه‌ای ارسال
- فاصله بین پیام‌ها
- زمان‌بندی و لغو زمان‌بندی
- تاریخچه و گزارش
- خروجی CSV
- تنظیمات فارسی

### توجه
این برنامه برای ارسال پیام به مخاطبانی طراحی شده که رضایت دریافت پیام دارند و برای دور زدن محدودیت‌های اپراتور یا سامانه‌های ضداسپم استفاده نمی‌شود.
